# Bhanu Pratap Portfolio

A responsive personal portfolio built with HTML, CSS and JavaScript.

## Files
- `index.html` — portfolio content
- `style.css` — design and responsive layout
- `script.js` — mobile navigation and year
- `assets/profile.jpg` — profile photo
- `assets/azure-fundamentals.pdf` — certificate

## Publish on GitHub Pages
1. Create a GitHub repository (for example: `bhanu-portfolio`).
2. Upload all files while keeping the `assets` folder.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main` and `/root`.
5. Save and open the generated GitHub Pages URL.

Note: The seven Python project cards are intentionally placeholders so the portfolio does not falsely claim projects you haven't provided names/links for yet.
